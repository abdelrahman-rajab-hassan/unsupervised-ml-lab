# Unsupervised Learning

This repository contains a collection of notebooks, scripts, and utilities covering a wide range of unsupervised learning techniques. It includes hands-on implementations of clustering algorithms, dimensionality reduction methods, and exploratory data analysis workflows — built and refined through practical exercises and real-world datasets.

## What's Inside
- **Clustering:** K-Means, DBSCAN, Hierarchical Clustering
- **Dimensionality Reduction:** PCA, t-SNE, UMAP
- **Anomaly Detection:** Isolation Forest, Local Outlier Factor
- **Utilities:** Custom helper functions and reusable preprocessing pipelines

## Purpose
This repository serves as both a personal reference and a portfolio of my journey through unsupervised machine learning — from foundational concepts to more advanced applications.
